# Calculadora de Índice de Massa Corpórea

Uma calculadora de IMC com base na altura e no peso informados pelo usuário, retornando: classificação de acordo com o IMC, limites saudáveis de peso e recomendações relacionadas ao resultado obtido.

---

## Funcionalidades

* **Cálculo de IMC e classificação:** realiza o cálculo do IMC utilizando a fórmula: peso/altura². Em seguida, o usuário recebe uma classificação de acordo com o valor obtido e os limites definidos para cada categoria: baixo peso, peso adequado, sobrepeso e obesidade (I, II e III).
* **Limites e recomendação:** o usuário é informado sobre a faixa saudável de peso para sua altura (mínimo e máximo) e recebe uma recomendação para manter, ganhar ou perder peso, conforme sua classificação.

---

## Tecnologias Utilizadas

* **Linguagem:** Python 3.14.5 (Stable)
